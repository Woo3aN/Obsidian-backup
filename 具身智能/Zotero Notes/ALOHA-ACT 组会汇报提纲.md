# ALOHA / ACT 组会汇报提纲

> 配套精读笔记：[[Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware]]
> 论文：arXiv 2304.13705，RSS 2023，Stanford / Berkeley / Meta

## 0. 一句话定位（开场就用这句）

> 这是 2023 年的工作，现在几乎所有 VLA（OpenVLA、π0、RDT）都会引它。它证明了两件事：
> **① 2 万美元的硬件能干毫米级的活；② 50 条示教就够学会。**

它不是一个新模型，是**一套系统**：便宜的硬件（ALOHA）+ 能学会的算法（ACT）。

## 1. 15 分钟骨架

| 时间 | 内容 | 关键动作 |
|---|---|---|
| 1 min | **定位**：这是 VLA 的「祖师爷之一」，但路线和后来的大模型相反 | 先说结论，别铺垫 |
| 2 min | **问题**：精细操作需要毫米级 + 接触力 + 闭环视觉；以前只能靠贵硬件。这篇问：能不能用学习补硬件？ | 举调料杯的例子（拨倒→滑进夹爪→挑盖） |
| 3 min | **两个贡献**：ALOHA（主从遥操作，关节空间映射，2 万美元）+ ACT（chunking + CVAE） | **强调是两个东西，不只一个算法** |
| 5 min | **核心机制**（重点） | 见下面第 2 节，这块要讲透 |
| 2 min | **结果**：6 个真实任务，多数 84-96%；**放视频** | 表格只挑 2 行 |
| 2 min | **局限 + 现在**：一个任务一个模型、没语言、穿扎带只有 20% | 说清楚演化方向 |

## 2. 核心机制：三个必讲点

### 点 1：compounding error（要讲清楚才显得懂）

> 一步偏 2mm → 到了训练时没见过的状态 → 模型在那儿继续错 → 越错越多。

论文的真实数字：穿扎带第一次抓偏几毫米，到半空第二次抓放大成 **10mm**，而孔只有 3mm。

**关键一句**：失败不是「模型学得差」，是**它被自己的小错带到了陌生地方**。

### 点 2：action chunking（论文的核心创新）

| | 普通做法 | chunking |
|---|---|---|
| 每次输出 | 1 个数（下一步） | **100 个数**（接下来 100 步） |
| 一次决定管多久 | 20ms | **2 秒** |
| 判断次数（400 步任务） | 400 次 | **4 次** |

**最有力的证据**（一定要讲这个）：

> 同一个模型、同一批数据，只改「一次出几步」：**k=1 时成功率 1%，k=100 时 44%。**

这就是「从完全不行到能用」的分界线，不是锦上添花。

**顺带提一句 temporal ensemble**：每步都重新预测，同一时刻的多个预测取平均，让动作平滑。但实测只贡献 **3.3%** —— 别把它讲得太重要。

### 点 3：CVAE（为什么不能用普通回归）

> 同一个画面，人可能有两种做法（往左拨倒 / 往右拨倒）。直接回归会学到两者的**平均值**，而平均值恰好是**把杯子推飞**的方向。

CVAE 的做法：先「概括这条示教属于哪种做法」压成一个 32 维向量 z，再在知道 z 的前提下预测动作。测试时 z 填 0。

**最有力的证据**：

| 训练数据 | 用 CVAE | 不用 CVAE |
|---|---|---|
| 脚本生成（完全确定） | 高 | 几乎无差别 |
| **人的示教（多模态）** | **35.3%** | **2%** |

**一句话总结**：人数据必须用生成式目标，这是全篇最硬的结论，也是后来 diffusion / flow matching 取代 CVAE 但结论不变的原因。

## 3. 必背数字

| 数字 | 是什么 |
|---|---|
| **$20k** | 整套硬件（两条 ViperX $5600×2 + 两条 WidowX $3300×2 + 相机 + 铝架） |
| **5–8mm** | ViperX 官方绝对精度（所以必须靠视觉闭环） |
| **50Hz** | 遥操作与记录频率（每步 20ms） |
| **14** | 双臂关节角维度（7+7，夹爪只占 1 维） |
| **4** | 相机数量，各 480×640 |
| **100** | chunk 长度 = 2 秒 |
| **1202** | 进 transformer 的 token 数（4×300 + 关节 1 + z 1） |
| **80M / 5h / 10ms** | 参数量 / 单卡 2080Ti 训练时长 / 推理延迟 |
| **50 条 · 10–20 分钟** | 每任务示教量（穿扎带 100 条） |
| **1% → 44%** | k=1 与 k=100 的成功率 |
| **35.3% → 2%** | 人数据下有无 CVAE |
| **88% / 96% / 84% / 20% / 64% / 92%** | 六个真实任务：Ziploc / Battery / Cup / Velcro / Tape / Shoe |
| **62%** | 50Hz 降到 5Hz 后，人自己操作慢了 62% |

## 4. 大概率被问到（答案一句话）

| 问题 | 一句话答案 |
|---|---|
| 为什么 k=100？ | 50Hz 下正好 2 秒 = 一个完整小动作的长度；太小省不了判断次数，太大等于闭眼走完（k=400 掉点） |
| temporal ensemble 贡献多少？ | 只 **3.3%**，主力是 chunking 本身。图 5 把它画得太重要，容易误读 |
| 为什么用 CVAE 不用 diffusion？ | 要**单次前向**（10ms）。diffusion 要几十到上百次去噪，50Hz 扛不住 |
| 50 条数据凭什么够？ | 50Hz 高频（一条 400-700 步）+ 滑动窗口复用（同一帧配 100 段后续 → 2 万样本）+ 单任务不求泛化 |
| 一个任务一个模型，算失败吗？ | 在它自己的目标里不算。作者 limitation 自己就写了「预训练、更多数据、更好感知是方向」 |
| 为什么不用预训练？ | 2023 年没有能用的机器人基座。它选了「小模型+少数据」，和同年 RT-1 的「大模型+大数据」是对立路线 |
| 20% 那个任务怎么解释？ | 穿扎带，孔 3mm，黑扎带贴黑桌面、对比度极低、占画面太小 —— 失败在**感知**，不在控制 |
| 这篇过时了吗？ | 架构过时（被 flow matching 取代），但**三个判断没过时**：高频示教、动作分块、生成式目标 |
| 和 OpenVLA 什么关系？ | 不是架构基础，是**问题定义的上游**。而且 OpenVLA 原版**没有** chunking，是后来的 OFT/π0 补回去的 |

## 6. 和 OpenVLA 的对照（有人读过 VLA 就甩这张）

| | ACT (2023) | OpenVLA (2024) |
|---|---|---|
| 视觉 | ResNet18 | SigLIP + DINOv2 双塔 |
| 主干 | 小 transformer，从零训 | Llama 2 7B |
| 动作 | 连续值，一次出 **100 步** | 离散 token，一次出 **1 步** |
| 语言 | 无 | 有 |
| 数据 | 50 条自采 | 97 万条 |
| 参数 | 80M | 7B（**87 倍**） |
| 强在哪 | 单任务精度、可复现 | 跨任务泛化 |

**一句话**：一个用「少而精」证明精细操作能做，一个用「多而广」证明泛化能做。2024 年底大家才发现两个都得要。

## 7. 两个实操建议

1. **放视频**。项目页 `tonyzhaozh.github.io/aloha` 有每个任务的视频。讲 20 分钟架构，不如放 30 秒「机器人自己开调料杯盖」。
2. **准备一句收尾**：「这篇的架构已经过时了，但它定的三件事 —— 高频示教、动作分块、生成式目标 —— 一次都没被推翻。」

## 8. 如果要加「现在怎么样了」（1-2 分钟）

- **触觉成了主线**：T-Rex（Berkeley，2026）发现**直接把触觉接到 π0.5 上反而更差**，因为触觉比视觉快一个数量级，必须用「双时钟」架构
- **采数据的方式被推翻了**：一作 Tony Zhao 退学创办 Sunday，改用**传感手套**采人类数据（1000 万 episodes / 500 个家庭），模型还叫 ACT-1/ACT-2，叠衣服 99.1%
- **产业已经有真实数字**：邮政分拣 1200 件/小时、汽车厂单工站 98%、2026 上半年全国出货 4 万台
- **但要打折扣**：4 万台 vs 手机一年十几亿台；「98%」是单工站几十次试验；信通院自己说「数据-模型-本体-场景难以闭环」

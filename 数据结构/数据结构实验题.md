## 1. 约瑟夫环（Josephus）

> 源码：`PTA/1/Josephus.cpp`

### 题目大意

有 $n$ 个人围成一圈，按顺序编号为 $1 \sim n$。从第 1 个人开始从 1 报数，报到 $p$ 的人出列，出列后下一个人继续从 1 开始报数。要求按顺序输出全部出列编号。

### 思路

经典约瑟夫环问题，用**递推公式**直接求出列序列，无需真的模拟链表：

- 设 `Josephus(n, k, i)` 表示：$n$ 个人中，第 $i$ 个出列的人的编号（从 0 开始计数）。
- **递推核心**：每淘汰一个人后，剩下 $n-1$ 个人的子问题与原问题存在位置偏移 $k$，即：

$$J(n, k, i) = \big(J(n-1, k, i-1) + k\big) \bmod n$$

- **边界**：最后一个出列的人（$i = 1$，即子问题只剩 1 人规模逆推的起点）编号为 $(k - 1 + n) \bmod n$。
- 最后把 0 开始的编号 $+1$ 转换为 $1 \sim n$ 输出即可。

时间复杂度：$O(n^2)$（共 $n$ 个出列位置，每个递推 $O(n)$ 深度），对本题规模足够。

### 代码

```cpp
#include <iostream>
using namespace std;

// 求 n 个人报数 k，第 i 个出列者的编号（0 起始）
int Josephus(int n, int k, int i)
{
    if (i == 1)
        // 边界：i=1 时由递推公式的起点直接得出
        return (k - 1 + n) % n;
    else
        // 递推：规模为 n-1 的子问题答案向右偏移 k，再对 n 取模
        return (Josephus(n - 1, k, i - 1) + k) % n;
}

int main()
{
    int n, p;
    cin >> n >> p;

    // 依次求第 1 ~ n 个出列的人
    for (int i = 1; i <= n; i++)
    {
        // 公式结果是 0 起始编号，+1 转成 1~n 的人类编号
        cout << Josephus(n, p, i) + 1;
        if (i != n)          // 数字之间用空格分隔，末尾不留空格
            cout << " ";
    }

    return 0;
}
```

## 2. 链表去重（Linked List - Remove Duplicates）

> 源码：`PTA/2/linked list-remove  duplicates.cpp`

### 题目大意

给定一条带头地址的单链表（结点格式：`地址 键值 下一地址`）。要求遍历链表，把**键值的绝对值重复**的结点删掉——保留下来的结点构成去重后的链表 $L_1$，被删除的结点按原顺序串成另一条链表 $L_2$。依次输出这两条链表。

### 思路

这是 PTA 典型的**静态链表**题（结点按地址散落存储，需要自己按下标索引）：

1. **静态建表**：用数组 `dat[]` 按输入顺序存结点，`id_to_node[地址] = 数组下标` 建立"地址 → 结点"的映射，之后就能沿 `nextid` 顺序遍历真实链表。
2. **判重**：开一个标记数组 `st[]`（键值绝对值范围有限），遍历时第一次遇到某绝对值就保留并标记，之后遇到就推入 `v`（待删除链表）。
3. **输出技巧**：链表输出格式是"当前结点地址 值 下一结点地址"，但下一结点地址必须等遍历到下一个结点才知道。所以采用**延迟输出**：除首结点外，打印某结点时先把上一结点的地址作为它的前驱行打印出来（`%05d\n%05d %d `），最后补 `-1` 结尾。
4. 保留链表先输出（末尾 `-1`），再同样格式输出被删结点链表（若为空则不输出）。

时间复杂度：$O(n)$。

### 代码

```cpp
#include <iostream>
#include <cmath>
#include <vector>
using namespace std;

const int N = 100010;

struct node
{
    int id, val, nextid;   // 结点地址、键值、下一结点地址
} dat[N];                  // 静态数组存所有结点

int id_to_node[N];         // 地址 -> dat 下标 的映射，用于按地址找结点
int st[N];                 // st[|val|] 标记该绝对值是否已保留
vector<node> v;            // 存放被删除（绝对值重复）的结点

int main()
{
    int head, n;
    cin >> head >> n;

    // 读入 n 个结点，并建立地址映射
    for (int i = 0; i < n; i++)
    {
        cin >> dat[i].id >> dat[i].val >> dat[i].nextid;
        id_to_node[dat[i].id] = i;
    }

    // 从头结点沿 nextid 遍历真实链表
    int verid = head;
    while (verid != -1)
    {
        int vernode = id_to_node[verid];      // 地址转下标
        if (st[abs(dat[vernode].val)] == 0)   // 该绝对值第一次出现 -> 保留
        {
            st[abs(dat[vernode].val)] = 1;    // 打标记
            if (verid == head)
            {
                // 链表第一个结点：直接打印，没有前驱行
                printf("%05d %d ", dat[vernode].id, dat[vernode].val);
            }
            else
            {
                // 延迟输出：先补上一行的"下一地址"，再打印当前结点
                printf("%05d\n%05d %d ", dat[vernode].id, dat[vernode].id, dat[vernode].val);
            }
        }
        else
        {
            v.push_back(dat[vernode]);        // 绝对值重复，归入删除链表
        }
        verid = dat[vernode].nextid;          // 跳到下一个结点
    }
    cout << "-1\n";                           // 保留链表以 -1 结尾

    // 同样的延迟输出方式打印被删除结点组成的链表
    for (int i = 0; i < v.size(); i++)
    {
        if (i == 0)
        {
            printf("%05d %d ", v[i].id, v[i].val);
        }
        else
        {
            printf("%05d\n%05d %d ", v[i].id, v[i].id, v[i].val);
        }
    }
    if (v.size())                             // 删除链表非空才输出结尾 -1
        cout << "-1";
    return 0;
}
```

## 3. 机器翻译（Machine Translation）

> 源码：`PTA/3/machine translation.cpp`

### 题目大意

翻译软件的内存容量为 $M$，文章长度为 $N$。依次扫描文章中的每个单词（单词编号为整数），遇到**内存中没有**的单词就要去词典查（记一次查词典次数），并把该单词存入内存；若内存已满，则删除**最早进入内存**的单词。求整个翻译过程共需要查多少次词典。

### 思路

典型的 **FIFO 队列 + 标记数组**模拟题（NOIP 2010 普及组原题）：

- 队列 `q` 维护当前内存中的单词，顺序即进入顺序；
- `st[x]` 标记单词 $x$ 是否在内存中，保证 $O(1)$ 判断"是否需要查词典"；
- 每读入一个单词：
  - 若 `st[x]` 为真 → 内存命中，跳过；
  - 否则查词典次数 `res++`；若内存已满（`q.size() == m`），先弹出队首并清除它的标记，再把新单词入队并标记。

时间复杂度：$O(n)$。

### 代码

```cpp
#include <iostream>
#include <queue>
using namespace std;

const int N = 1010;

int m, n;
bool st[N];        // st[x]：单词 x 当前是否在内存中

int main()
{
    cin >> m >> n;               // 内存容量 m，文章长度 n

    queue<int> q;                // 队列模拟内存，先进先出
    int res = 0;                 // 查词典次数（答案）

    for (int i = 0; i < n; i++)
    {
        int x;
        cin >> x;                // 读入当前单词

        if (!st[x])              // 内存中没有 -> 需要查词典
        {
            if (q.size() == m)   // 内存已满：淘汰最早进入的单词（队首）
            {
                int t = q.front();
                st[t] = false;   // 清除它的"在内存"标记
                q.pop();
            }

            q.push(x);           // 新单词入队
            st[x] = true;        // 标记为在内存中
            res++;               // 记一次查词典
        }
        // 内存中已有该单词：直接用，不计次数
    }

    cout << res << endl;         // 输出总查词典次数
    return 0;
}
```

## 4. 多项式求值（Polynomial Summation）

> 源码：`PTA/4/Polynomial Summation.cpp`

### 题目大意

给定一元 $n$ 次多项式的阶数 $n$、自变量取值 $x$，以及 $n+1$ 个系数 $a_0 \sim a_n$，计算多项式 $f(x)$ 的值，结果保留 3 位小数。

### 思路

用**秦九韶算法（Horner 法）**，把多项式改写为嵌套形式，一边读系数一边计算：

$$f(x) = (\cdots((a_0 \cdot x + a_1) \cdot x + a_2) \cdot x + \cdots) \cdot x + a_n$$

- 递推式只有一步：`res = res * x + a`；
- 相比逐项计算 $a_i x^i$ 再累加，避免了幂运算，时间复杂度从 $O(n^2)$ 降到 $O(n)$，且精度更好；
- 读入用 `scanf` 读 `double`（`%lf`），输出 `printf("%.3lf")` 保留三位小数。

### 代码

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n;
    double x;

    scanf("%d %lf", &n, &x);     // 阶数 n，自变量 x

    double a;
    double res = 0;              // res 即秦九韶算法的累计结果

    // 依次读入 n+1 个系数 a0 ~ an
    for (int i = 0; i <= n; ++i)
    {
        scanf("%lf", &a);
        res = res * x + a;       // 秦九韶核心：先乘 x 再加新系数
    }

    printf("%.3lf\n", res);      // 保留 3 位小数输出
    return 0;
}
```

## 5. 最长连续递增子序列（Longest Increasing Continuous Subsequence）

> 源码：`PTA/5/Longest Increasing Continuous Subsequence.cpp`

### 题目大意

给定 $n$ 个整数组成的序列，找出其中**最长的一段连续递增子序列**（即位置连续、且数值严格递增的一段），并输出该子序列。

### 思路

**一次线性扫描**（双指针/滑动窗口思想）：

- 用 `st` 记录当前递增段的起点，`len` 记录当前段长度；
- 从第 2 个元素开始扫描：
  - 若 `a[i] > a[i-1]`，当前段延长，`len++`；
  - 否则递增中断，先把当前段与全局最优（`ms` 起点、`ml` 长度）比较更新，再从 `i` 开启新段（`st = i, len = 1`）；
- **扫描结束后还要再比较一次**：最后一段没有遇到"中断点"，不比较就会漏掉答案最长的情形（常见易错点）；
- 最后从起点 `ms` 输出 `ml` 个数。

时间复杂度：$O(n)$，空间 $O(n)$。

### 代码

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n;
    int a[100005];
    cin >> n;
    for (int i = 0; i < n; i++)
        cin >> a[i];             // 读入序列

    int st = 0, len = 1;         // st：当前递增段起点；len：当前段长度
    int ms = 0, ml = 1;          // ms：最优段起点；ml：最优段长度

    for (int i = 1; i < n; i++)
    {
        if (a[i] > a[i - 1])     // 仍严格递增，当前段延长
            len++;
        else                     // 递增中断
        {
            if (len > ml)        // 用当前段更新全局最优
            {
                ml = len;
                ms = st;
            }

            st = i;              // 从 i 开启新的递增段
            len = 1;
        }
    }

    // 易错点：最后一段没有"中断点"触发比较，必须单独再比一次
    if (len > ml)
    {
        ml = len;
        ms = st;
    }

    // 从最优起点连续输出 ml 个数
    for (int i = 0; i < ml; i++)
    {
        if (i)                   // 数字间用空格分隔
            cout << " ";
        cout << a[ms + i];
    }

    return 0;
}
```

## 6. 两个有序链表序列的交集（Intersection of Two Sorted Linked Lists）

> 源码：`PTA/6/Intersection of Two Sorted Linked Lists.cpp`

### 题目大意

已知两个**非降序**排列的整数序列（各自以 `-1` 结尾，模拟两条有序链表），求它们的交集，同样按非降序输出；若交集为空，输出 `NULL`。

### 思路

**归并式双指针**，与归并排序的合并过程同构：

- `i`、`j` 分别指向两个序列的当前位置：
  - `s1[i] < s2[j]`：`s1[i]` 不可能在 `s2` 中出现，`i++`；
  - `s1[i] > s2[j]`：同理 `j++`；
  - 相等：找到一个交集元素，存入 `s3`，两指针同时后移（保证去重——同一对相等的值只会被取一次）；
- 由于两序列各自有序，扫描一趟即可完成，时间复杂度 $O(|S_1| + |S_2|)$；
- 交集为空输出 `NULL`，否则空格分隔输出。

> 思路延伸：同样的双指针模式稍作改动即可用于求**并集**（都保留）与**差集**（只保留不属于另一方的元素）。

### 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> s1, s2;
    int x;

    // 读入第一条有序序列，-1 为结束标志
    while (cin >> x && x != -1)
    {
        s1.push_back(x);
    }

    // 读入第二条有序序列
    while (cin >> x && x != -1)
    {
        s2.push_back(x);
    }

    vector<int> s3;              // 存放交集结果
    int i = 0, j = 0;            // 双指针分别扫描两条序列

    while (i < s1.size() && j < s2.size())
    {
        if (s1[i] < s2[j])       // s1 的当前元素偏小，不可能在交集里
            i++;

        else if (s1[i] > s2[j])  // s2 的当前元素偏小
            j++;

        else                     // 两边相等：命中一个交集元素
        {
            s3.push_back(s1[i]);
            i++;                 // 双指针同时后移，天然去重
            j++;
        }
    }

    if (s3.empty())
    {
        cout << "NULL" << endl;  // 交集为空
    }
    else
    {
        for (int k = 0; k < s3.size(); k++)
        {
            cout << s3[k];
            if (k < s3.size() - 1)  // 空格分隔，末尾无多余空格
                cout << " ";
        }
        cout << endl;
    }

    return 0;
}
```

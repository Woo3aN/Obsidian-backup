## 2-1 分支结构的时间复杂度

> [!question] 题目（2 分 · 作者 陈越 · 浙江大学）
> 设 $0 \le i, k < n$，下面这段代码的时间复杂度是：
>
> ```c
> if (i>k) {
>     for (j=i; j<n; j++)
>         a[j] = a[j-k]+1;
> }
> else {
>     for (j=i; j>0; j--)
>         a[j] = a[k-j]+2;
> }
> ```
>
> - A. $O(n)$
> - B. $\Theta(kn)$
> - C. $\Omega(n)$
> - D. $\Theta(n\log n)$

> [!success] 答案：A

### 解答

$i$、$k$ 是**给定参数**（一旦给定就是常数），只需对 $n$ 取渐进。

- `if (i>k)`：$j$ 从 $i$ 走到 $n-1$，共 $n-i$ 次
- `else`：$j$ 从 $i$ 递减到 $1$，共 $i$ 次

所以 $T(n)=n-i$ 或 $i$，落在 $[0,\ n-1]$ 内：最坏 $\Theta(n)$（如 $k=n-1,\ i=n-1$），最好 $\Theta(1)$（$i=0$ 一次也不跑）。

逐项判断：

- **A. $O(n)$** ✅ 任何取值下 $T(n)\le n$，上界成立
- **B. $\Theta(kn)$** ❌ $k$ 只参与比较和下标运算，是 $O(1)$，没有乘性因子
- **C. $\Omega(n)$** ❌ $i=0$ 时执行 0 次，下界不成立
- **D. $\Theta(n\log n)$** ❌ 单层循环，无嵌套、无折半

> [!warning] 两个陷阱
> - 两个分支**互斥**，时间取最大而不是相加；$n-i+i=n$ 正好是个诱饵。
> - 只有问"最坏情况"才能答 $\Theta(n)$；选项只给上界，就只能选 $O$。

### 知识点

1. **三种记号**：$O$ 上界、$\Omega$ 下界、$\Theta$ 紧确界。问"复杂度"一般默认最坏情况的紧确界，但选项只给上界时只能选上界。
2. **分支取最大**：$T=\max(T_1,T_2)$，不是求和。
3. **循环次数**：`for(j=i;j<n;j++)` 是 $n-i$ 次，`for(j=i;j>0;j--)` 是 $i$ 次；单层循环 + $O(1)$ 循环体 → $O(n)$，有嵌套或折半才会升到 $O(n^2)$、$O(\log n)$。
4. **参数不是规模**：只有随 $n$ 增长的量才进阶。

## 2-2 三层嵌套循环的语句频度

> [!question] 题目（5 分 · 作者 严蔚敏 · 清华大学）
> 设 $n$ 为正整数，试确定程序段中前置以 `@` 标记的语句的频度。
>
> ```c
> for (i=1; i<=n; i++)
>     for (j=1; j<=i; j++)
>         for (k=1; k<=j; k++)
>             @ x += delta;
> ```
>
> - A. $\frac{1}{12}n(n+1)(2n+1)$
> - B. $\frac{1}{12}n(n+1)(2n+3)$
> - C. $\frac{1}{6}n(n+1)(n+2)$
> - D. $\frac{1}{6}n(n+1)(2n+1)$

> [!success] 答案：C

### 解答

每给出一组 $(i,j,k)$，`@` 执行一次，所以频度就是三元组的个数，逐层求和即可：

$$f(n)=\sum_{i=1}^{n}\sum_{j=1}^{i}\sum_{k=1}^{j}1=\sum_{i=1}^{n}\sum_{j=1}^{i}j=\sum_{i=1}^{n}\frac{i(i+1)}{2}$$

代入 $\sum i$ 和 $\sum i^2$：

$$f(n)=\frac{1}{2}\left[\frac{n(n+1)(2n+1)}{6}+\frac{n(n+1)}{2}\right]=\frac{n(n+1)}{4}\cdot\frac{2n+4}{3}=\frac{n(n+1)(n+2)}{6}$$

与 C 一致。验算 $n=2$：实际 $1+3=4$，C 给 $2\cdot3\cdot4/6=4$ ✅。

干扰项位置：D 是 $\sum i^2=\frac{n(n+1)(2n+1)}{6}$，对应"把最内层每轮次数错当成 $i$"的算法；A 是 D 的一半。

> [!warning] 技巧
> 这种"每层都从 1 数到上一层变量"的嵌套，求和结果是组合数：三层是 $\binom{n+2}{3}$，一般 $m$ 层是 $\binom{n+m-1}{m}$。本题直接 $\binom{n+2}{3}=\frac{n(n+1)(n+2)}{6}$，一步出答案。

### 知识点

1. **频度**（语句执行次数）就是嵌套循环的总迭代数，逐层"内层次数 × 外层取值"再求和，不是各层上限相乘。
2. **必背求和公式**：$\sum i=\frac{n(n+1)}{2}$，$\sum i^2=\frac{n(n+1)(2n+1)}{6}$。选项里出现 $(2n+1)$ 基本就是在考 $\sum i^2$。
3. **组合恒等式**：$\sum_{i=1}^{n}\binom{i+1}{2}=\binom{n+2}{3}$；$m$ 层嵌套（层上限均为上一层变量）$=\binom{n+m-1}{m}$。
4. **小 $n$ 验算**：代 $n=1$ 得实际值 $1$，而 A 给 $1/2$、B 给 $5/6$、C 和 D 都给 $1$；再代 $n=2$（实际 $4$），D 给 $5$ —— 两轮就能锁定 C。

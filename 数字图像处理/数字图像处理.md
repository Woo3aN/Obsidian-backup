## 课程概述

### 什么是图像与视频处理？

图像与视频处理是让计算机能够理解、分析和操控图像与视频内容的技术领域。它与**计算机视觉**关系密切，但侧重点有所不同——图像处理更关注对图像本身的操作与增强。

### 典型应用场景

| 领域 | 应用 | 说明 |
|------|------|------|
| **太空探索** | 火星车图像压缩 | NASA/JPL 使用图像压缩算法将火星图像传回地球，Sapiro教授的算法曾被选入火星车 |
| **电影工业** | 图像修复 / 特效 | 去除电影穿帮镜头、修复划痕、抠图换背景、黑白上色、动态模糊特效 |
| **医学影像** | 神经外科 / HIV研究 | MRI/CT 图像引导电极植入；HIV病毒包膜（gp120/gp41）三维结构重建 |
| **日常应用** | 数码相机 / 网络视频 | 图像压缩（JPEG）、视频压缩（用于在线视频流） |

### 课程结构（9周）

- **前4-5周**: 基础核心知识（压缩、增强、分割等）
- **后4周**: 前沿研究课题（先进技术）
- 每周包含短视频片段、小测验、推荐编程练习
- 参考教材为冈萨雷斯《数字图像处理》第三版

## 图像无处不在

### 电磁波谱中的图像

人类肉眼可见的光谱只占整个电磁波谱的**极小部分**。图像可以在极宽的频谱范围内被记录：

| 成像类型 | 频谱范围 | 典型应用 |
|----------|----------|----------|
| **可见光图像** | 可见光 | 日常摄影、自然图像 |
| **X光图像** | X射线 | 医学诊断、印刷电路板检测 |
| **紫外图像** | 紫外线 | 显微分析、生物成像 |
| **红外图像** | 红外线 | 卫星遥感、温度监测 |
| **微波/雷达图像** | 微波 | 气象卫星（如飓风追踪）、地形测绘 |
| **超声图像** | 超声波 | 医学超声诊断 |
| **显微图像** | 多种频谱 | 生物学研究、PCB检测 |

### 多模态成像

对**同一场景**使用**不同成像方式**可获得不同类型的信息。例如在医学中，MRI、CT、超声等各自提供互补的结构与功能信息。

### 工业与科学应用

- **自动检测**：印刷电路板（PCB）缺陷检测是图像处理最成功的工业应用之一
- **卫星遥感**：地表监测、天气预报、定位导航
- **安防监控**：车牌识别、人脸识别

## 人类视觉系统

理解人类视觉系统对图像处理至关重要，因为图像处理的"客户"就是人眼。

### 眼睛的解剖结构

- **角膜**（Cornea）：光线进入眼睛的第一道折射结构
- **晶状体**（Lens）：调焦，使图像清晰投射到视网膜
- **视网膜**（Retina）：布满感光传感器的感光层，位于眼球后方

### 感光细胞：两类传感器

视网膜上有两种感光细胞，功能互补：

| 特性 | 视锥细胞（Cones） | 视杆细胞（Rods） |
|------|-------------------|-------------------|
| **分布** | 集中在**中央凹（fovea）** | 分布在视网膜大部分区域 |
| **密度峰值** | 中央凹处密度最高 | 中央凹处极少 |
| **功能** | 处理**细节** | 处理**轮廓/整体结构** |
| **光照条件** | **亮光**下工作最佳 | **弱光**下工作最佳 |
| **颜色感知** | 负责颜色视觉 | 不感知颜色 |

> **中央凹（Fovea）**：视网膜上视觉最清晰的区域，密度最高的锥细胞聚集于此。人眼会下意识移动眼球，将感兴趣的对象投影到中央凹上。

### 盲点（Blind Spot）

视网膜上有一个区域**没有感光细胞**（视神经离开眼球的位置），但我们的视觉系统会自动"填补"这一区域，使我们无法察觉到这个盲点。这一现象与图像处理中的 **inpainting（图像修补）** 技术原理相通。

### 亮度适应

- 人眼能感知的**亮度范围极大**（跨越多个数量级，以对数刻度衡量）
- 但**无法同时**感知极大范围的亮度——需要适应过程
- 从暗处到亮处（或反向）的适应需要时间（如走进黑暗电影院后逐渐适应）

### 韦伯定律（Weber's Law）

**感知变化量 / 背景亮度 ≈ 常数**（ΔI / I ≈ 常数）

- 在**低亮度**条件下，需要较大的亮度变化才能被感知
- 在**高亮度**条件下，较小的亮度变化即可被感知
- 意义：设计图像显示设备和相机时，需要考虑人眼在不同亮度下的敏感度差异

### 视觉感知与错觉

人眼的感知**依赖于上下文/周边环境**，而非单纯取决于绝对亮度值：

1. **马赫带（Mach Bands）**：在相邻不同亮度的区域边界处，人眼会感知到更亮或更暗的"伪边界"——暗区在边界处显得更暗，亮区显得更亮。这是人眼的**边缘增强机制**。
2. **同时对比（Simultaneous Contrast）**：相同亮度的灰色方块放在不同背景上会显得亮度不同——深色背景上显得更亮，浅色背景上显得更暗。
3. **几何错觉**：如经典的长度错觉、平行线错觉等。

> 这些错觉在图像处理中具有重要意义，提示我们人眼并非"客观传感器"，理解这些特性才能设计出更好的图像处理算法。

## 图像形成——采样与量化

### 从连续到离散

图像形成的基本过程：

```
光线 → 被物体反射 → 进入相机 → 传感器阵列感知 → 离散化 → 数字图像
```

相机传感器是**二维传感器矩阵**，以正方形或长方形排列（如 1000×1000 传感器）。

### 两个核心离散化过程

#### 1. 空间采样（Spatial Sampling）

- **定义**：对连续空间在离散位置上的取值
- 传感器以一定间隔排列，每个传感器累积其接收到的光线
- **采样密度**决定**空间分辨率**——即像素数量
- 数码相机的"像素数"（megapixel）就是指采样密度

#### 2. 灰度量化（Gray-level Quantization）

- **定义**：对连续灰度值离散化为有限个等级
- 无法捕获所有层级的灰度值，只能用有限离散值近似
- **量化层级**决定**灰度分辨率**——即每个像素用多少比特表示

### 像素（Pixel）

- 称为 **picture element**（图像元素）的缩写
- 每个像素在**空间位置**和**灰度值**上都是离散的
- 常见配置：256×256 像素 × 8 bits（256个灰度级）

### 分辨率对图像质量的影响

#### 空间分辨率的影响

| 分辨率 | 效果 |
|------|------|
| 高（大量像素） | 细节清晰、边缘锐利 |
| 低（少量像素） | 模糊、锯齿效应、细节丢失 |

#### 灰度分辨率的影响

| 比特数 | 灰度级数 | 效果 |
|--------|---------|------|
| 8 bits | 256 | 平滑自然 |
| 7 bits | 128 | 轻微质量下降 |
| 6 bits | 64 | 开始出现**伪轮廓（False Contouring）** |
| 5 bits | 32 | 伪轮廓明显 |
| 4 bits | 16 | 严重条带状伪影 |
| 3 bits | 8 | 极低质量 |
| 2 bits | 4 | 近似卡通效果 |
| 1 bit | 2 | 黑白二值图 |

> **伪轮廓（False Contouring）**：当灰度级数不足时，平滑过渡区域会出现明显的带状分界，看起来像等高线。这是灰度量化不足的典型表现。

### 饱和度（Saturation）

当场景中某区域亮度过高，超过了可表示的最大灰度值时，该区域所有像素值都会被"截断"为最大值（如255），表现为一片**全白区域（高光溢出）**。这是由于传感器的**离散值范围有限**所致。

### 量化运算示例

将灰度值从256级降到更低等级的基本操作：
1. 除以 N（目标下降倍数）
2. 向下取整
3. 乘以 N

例如：256级→128级：`val = floor(val / 2) * 2`（9 → 8，丢失奇数信息）

## 彩色图像与视频表示

### RGB 颜色模型

彩色图像由**三个通道**表示：

| 通道 | 含义 |
|------|------|
| R（Red） | 场景中的红色分量 |
| G（Green） | 场景中的绿色分量 |
| B（Blue） | 场景中的蓝色分量 |

每个通道是一个二维离散数组，与灰度图像相同。

### 彩色的像素表示

- 每个像素由 **24 bits** 表示：R（8 bits）+ G（8 bits）+ B（8 bits）
- 共可表示 2^24 ≈ 1670 万种颜色

### 相机的彩色成像：拜耳马赛克（Bayer Mosaic）

大多数中低端消费级数码相机**并非**直接捕获三个完整的颜色通道，而是使用**单层彩色滤光片阵列 (CFA)**：

```
R G R G ...
G B G B ...
R G R G ...
G B G B ...
```

- 每个传感器只捕获一种颜色分量
- 需要**去马赛克（Demosaicing / 插值）** 来补全每个像素的 R、G、B 值
- 插值利用邻近像素的信息来完成三个颜色通道
- 相机标称的像素数通常是**插值后**的结果，实际捕获的原始数据约为标称值的**1/3**
- 将在课程第3-4周详述

> 高端相机使用三传感器（3-CCD/3-CMOS）则能真实捕获三个完整的颜色通道，无需插值。

### 视频表示

- **帧（Frame）**：视频中的每一张静态图像
- 视频是**帧的序列**，常见帧率：
  - 30 帧/秒（fps）
  - 24 帧/秒（电影标准）
- 一秒视频的存储需求（示例）：
  - 分辨率 512×512，24 bits/像素，30 fps
  - 计算：512 × 512 × 3 通道 × 30 帧 ≈ **23.6 MB/秒**

### 总结：图像在计算机中的表示

| 图像类型 | 数据结构 |
|----------|---------|
| **灰度图像** | 一个二维离散数组（M × N） |
| **彩色图像** | 三个二维离散数组（M × N × 3）：R、G、B |
| **视频** | 多个二维/三维数组的序列（帧数 × M × N × 通道数） |

> 图像在计算机中本质上就是**元素为离散值的二维数组**（灰度图）或三维数组（彩色图）。

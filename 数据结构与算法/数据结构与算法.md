## 动态规划

### 背包 DP 概述

**背包问题（Knapsack Problem）** 是经典的组合优化问题：在容量有限的背包中装入若干物品（各有体积 / 重量与价值），在不超过容量上限的前提下求最大总价值。

按物品的可选次数分为三类，核心都是一维滚动数组：

| 类型    | 物品限制          | 核心处理             | 时间复杂度                      |
| :---- | :------------ | :--------------- | :------------------------- |
| 01 背包 | 每件最多取 1 次     | 内层**倒序**         | $O(NV)$                    |
| 完全背包  | 每件可取无限次       | 内层**正序**         | $O(NV)$                    |
| 多重背包  | 每件最多取 $s_i$ 次 | **二进制拆分** + 内层倒序 | $O(\sum \log s_i \cdot V)$ |

> 01 背包与完全背包的**唯一区别**是内层循环方向；多重背包则需先**二进制拆分**，再按 01 背包处理。推导详见下方各题笔记。

```cpp
// 01 背包：内层倒序，每件物品只能用一次
for (int i = 1; i <= n; i++)
    for (int j = m; j >= v[i]; j--)
        f[j] = max(f[j], f[j - v[i]] + w[i]);

// 完全背包：内层正序，每件物品可无限使用
for (int i = 1; i <= n; i++)
    for (int j = v[i]; j <= m; j++)
        f[j] = max(f[j], f[j - v[i]] + w[i]);

// 多重背包：先二进制拆分，再按 01 背包（倒序）处理
int cnt = 0;
for (int i = 1; i <= n; i++)
{
    int a, b, s;                    // 体积、价值、数量
    cin >> a >> b >> s;
    int k = 1;
    while (k <= s)                  // 1, 2, 4, ...
    {
        cnt++;
        v[cnt] = a * k;
        w[cnt] = b * k;
        s -= k;
        k *= 2;
    }
    if (s > 0)                      // 余数
    {
        cnt++;
        v[cnt] = a * s;
        w[cnt] = b * s;
    }
}
for (int i = 1; i <= cnt; i++)
    for (int j = m; j >= v[i]; j--)
        f[j] = max(f[j], f[j - v[i]] + w[i]);
```

### 01 背包问题

- **来源**：AcWing 2. 01 背包问题 / AcWing 423. 采药（XMUOJ JDII198 改编）
- **难度**：Low

#### 题目描述

有 $M$ 件物品和一个容量为 $T$ 的背包：

- 第 $i$ 件物品体积为 $v_i$，价值为 $w_i$；
- 每件物品**只有一件**，取或不取（对应 01 背包）。

求在总体积不超过 $T$ 的条件下，能获得的最大总价值。

**输入**：第一行两个整数 $T, M$（背包容量、物品数），用空格隔开；接下来 $M$ 行，每行两个整数 $v_i, w_i$（体积、价值）。

**数据范围**：$1 \le T \le 1000$，$1 \le M \le 100$。

**样例**

```text
70 3
71 100
69 1
1 2
```

```text
3
```

#### 思路

**朴素二维写法**

$$
dp[i][j] = \text{从前 } i \text{ 件物品中选、容量不超过 } j \text{ 时的最大价值}
$$

对第 $i$ 件物品，分「取」与「不取」两种情况：

$$
dp[i][j] = \max\Big(dp[i-1][j],\ dp[i-1][j - v_i] + w_i\Big)
$$

- 不取：$dp[i-1][j]$；
- 取（需 $j \ge v_i$）：$dp[i-1][j - v_i] + w_i$。

初始化 $dp[0][j] = 0$，答案即 $dp[M][T]$。时间 $O(M \times T)$，空间 $O(M \times T)$。

**一维滚动数组优化**

观察转移方程，第 $i$ 行只依赖第 $i-1$ 行，可压成一维：

$$
dp[j] = \max\Big(dp[j],\ dp[j - v_i] + w_i\Big)
$$

内层 $j$ 必须**从大到小（倒序）** 遍历：

```cpp
for (int j = m; j >= v[i]; j--)
    f[j] = max(f[j], f[j - v[i]] + w[i]);
```

**为什么倒序？** 转移用到的 $dp[j - v_i]$ 必须是「前 $i-1$ 件」的旧值。若正序遍历，$dp[j - v_i]$ 已在当前轮被更新（可能已包含第 $i$ 件），会导致第 $i$ 件被重复选取，退化成完全背包。倒序保证当前轮更新的 $dp[j]$ 不会影响本轮更大的 $j$，每种物品至多取一次。

**复杂度**

- 时间：$O(M \times T)$
- 空间：$O(T)$（一维）

**样例验证**：容量 $T = 70$，第 1 件（$71, 100$）体积 $71 > 70$ 放不下；第 2 件（$69, 1$）+ 第 3 件（$1, 2$）共耗时 $69 + 1 = 70$，价值 $1 + 2 = 3$，为最大。

#### 代码实现

```cpp
#include <cstring>
#include <iostream>
#include <algorithm>

using namespace std;

const int N = 1010;

int m, n;
int f[N];

int main()
{
    cin >> m >> n;

    // 读入即处理，无需存储全部物品
    for (int i = 0; i < n; i++)
    {
        int v, w;
        cin >> v >> w;
        // 01 背包：内层倒序遍历
        for (int j = m; j >= v; j--)
            f[j] = max(f[j], f[j - v] + w);
    }

    cout << f[m] << endl;

    return 0;
}
```

### 完全背包问题

- **来源**：AcWing 3. 完全背包问题（XMUOJ JDII122 改编）
- **难度**：High

#### 题目描述

有 $N$ 种物品和一个容量为 $V$ 的背包：

- 第 $i$ 种物品体积为 $v_i$，价值为 $w_i$；
- 每种物品**数量无限**，可取任意件。

求能装入背包的最大总价值。

**输入**：第一行两个整数 $N, V$，用空格隔开；接下来 $N$ 行，每行两个整数 $v_i, w_i$。

**样例**

```text
7 884
6148 6786
8500 8620
6136 6930
8700 6732
409 3388
9925 642
4324 5208
```

```text
6776
```

#### 思路

**状态定义**

$$
dp[j] = \text{容量为 } j \text{ 时能获得的最大总价值}
$$

初始化全部为 $0$（什么都不装的价值为 $0$）。

**状态转移**

对每种物品 $i$，**正序**遍历容量 $j$（从 $v_i$ 到 $V$）：

$$
dp[j] = \max\Big(dp[j],\ dp[j - v_i] + w_i\Big)
$$

**为什么正序？** 这是完全背包与 01 背包唯一的不同点：

- **倒序**更新时，更新 $dp[j]$ 用到的 $dp[j - v_i]$ 是上一轮（不含第 $i$ 种物品）的结果，保证每种物品至多取一次；
- **正序**更新时，$dp[j - v_i]$ 可能已经放入了第 $i$ 种物品，于是该物品可以被**反复取用**，恰好实现「无限次」的限制。

**复杂度**

- 时间：$O(N \times V)$
- 空间：$O(V)$

**样例验证**：容量为 $884$，只有第 5 件物品体积 $409 \le 884$ 可装入，最多取 $\lfloor 884 / 409 \rfloor = 2$ 件，最大价值 $= 2 \times 3388 = 6776$。

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int N = 1010;
int n, m;
int v[N], w[N];
int f[N];

int main()
{
    cin >> n >> m;
    for (int i = 1; i <= n; i++)
        cin >> v[i] >> w[i];

    // 完全背包：内层正序遍历容量
    for (int i = 1; i <= n; i++)
        for (int j = v[i]; j <= m; j++)
        {
            f[j] = max(f[j], f[j - v[i]] + w[i]);
        }

    cout << f[m] << endl;

    return 0;
}
```

### 多重背包问题

- **来源**：AcWing 4. 多重背包问题 I（XMUOJ JDII126 改编）
- **难度**：High

#### 题目描述

有 $N$ 种物品和一个容量为 $V$ 的背包：

- 第 $i$ 种物品重量为 $w_i$、价值为 $v_i$、**数量最多 $s_i$ 件**；
- 每种物品最多取 $s_i$ 件。

求能装入背包的最大总价值。

**输入**：第一行两个整数 $N, V$，用空格隔开；接下来 $N$ 行，每行三个整数 $w_i, v_i, s_i$。

**样例**

```text
4 5
1 2 3
2 4 1
3 4 3
4 5 2
```

```text
10
```

#### 思路

多重背包 = 01 背包 + 数量限制。

**朴素做法**：把第 $i$ 种物品的 $s_i$ 件逐件拆开，视为 $s_i$ 件独立的 01 背包物品。但 $s_i$ 可能很大，复杂度 $O(\sum s_i \times V)$ 不可行。

**二进制拆分优化**

将 $s_i$ 分解为若干份：

$$
1,\ 2,\ 4,\ \dots,\ 2^k,\ \text{余数 } r
$$

其中 $1 + 2 + \dots + 2^k \le s_i$，余数 $r = s_i - (1 + 2 + \dots + 2^k)$。这些份的子集之和能覆盖 $0$ 到 $s_i$ 的**任意整数**，因此拆分后物品的选择范围与原题完全等价。

把每一份打包成一件新的 01 背包物品：

$$
\text{重量} = \text{份数} \times w_i, \qquad \text{价值} = \text{份数} \times v_i
$$

拆分后物品总数降为 $\sum \log s_i$，再跑标准 01 背包（内层**倒序**）：

$$
dp[j] = \max\Big(dp[j],\ dp[j - w] + v\Big)
$$

**为什么份数按 $1,2,4,\dots$ 取？** 二进制表示的任意整数都可由此拼出——例如 $s = 13 \Rightarrow 1,2,4,6$，子集和可覆盖 $0 \sim 13$。这样把「取 $k$ 件」这一维选择压缩成了 $\log s_i$ 个 01 决策。

**复杂度**

- 时间：$O\Big(\sum_i \log s_i \times V\Big)$
- 空间：$O(V)$

**进一步优化**：单调队列优化可将复杂度降至 $O(N \times V)$（对每种物品按模 $w_i$ 的剩余类分别维护滑动窗口最大值）。本题用二进制拆分即可满足要求。

**样例验证**：取 3 件物品 1（重 $3$、价 $6$）+ 1 件物品 2（重 $2$、价 $4$）= 总重量 $5$、总价值 $10$，恰好装满。

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>

using namespace std;

const int N = 12010, M = 2010;   // N: 拆分后的物品上限（Σlog s_i），M: 背包容积

int n, m;
int v[N], w[N];
int f[M];

int main()
{
    cin >> n >> m;
    int cnt = 0;                // 拆分后新物品的个数
    for (int i = 1; i <= n; i++)
    {
        int a, b, s;            // 重量、价值、数量
        cin >> a >> b >> s;
        int k = 1;
        while (k <= s)          // 按 1, 2, 4, ... 拆分
        {
            cnt++;
            v[cnt] = a * k;
            w[cnt] = b * k;
            s -= k;
            k *= 2;
        }

        if (s > 0)              // 剩余部分作为最后一件
        {
            cnt++;
            v[cnt] = a * s;
            w[cnt] = b * s;
        }
    }
    n = cnt;

    // 拆分完毕后跑标准 01 背包：内层倒序遍历
    for (int i = 1; i <= n; i++)
        for (int j = m; j >= v[i]; j--)
            f[j] = max(f[j], f[j - v[i]] + w[i]);

    cout << f[m] << endl;
    return 0;
}
```

### 多重背包·单调队列优化

- **来源**：AcWing 6. 多重背包问题 III（XMUOJ JDII208 改编）
- **难度**：High

#### 题目描述

有 $N$ 种物品和一个容量为 $V$ 的背包：

- 第 $i$ 种物品体积 $v_i$、价值 $w_i$、数量最多 $s_i$ 件；
- 每种物品最多取 $s_i$ 件。

求能装入背包的最大总价值。

**输入**：第一行两个整数 $N, V$；接下来 $N$ 行，每行三个整数 $v_i, w_i, s_i$。

**数据范围**：$0 < N \le 1000$，$0 < V \le 20000$，$0 < v_i, w_i, s_i \le 20000$。

**样例**

```text
4 5
1 2 3
2 4 1
3 4 3
4 5 2
```

```text
10
```

#### 思路

当 $V, s_i$ 都很大时，二进制拆分后的物品数 $\sum \log s_i \times V$ 仍可能超限，需要 $O(NV)$ 的**单调队列优化**。

多重背包的转移是：

$$
dp[j] = \max_{k \in [0, \min(s_i, \lfloor j/v_i \rfloor)]}\Big(dp[j - k\,v_i] + k\,w_i\Big)
$$

**按余数分组**：将容量 $j$ 按对 $v_i$ 取模的余数 $r$（$0 \le r < v_i$）分组，同一组内 $j = r,\ r+v_i,\ r+2v_i,\dots$。令 $t = (j - r)/v_i$，则

$$
dp[r + t\,v_i] = t\,w_i + \max_{u \in [t - s_i,\ t]}\Big(dp[r + u\,v_i] - u\,w_i\Big)
$$

括号内只与 $u$ 有关，而 $u$ 的取值区间 $[t - s_i, t]$ 是**长度固定的滑动窗口** → 对每个余数类维护一个单调队列，队首即窗口内的最大值：

- 队列中存容量下标 $k$，比较值 $dp[k] - \frac{k - r}{v_i}\,w_i$；
- 窗口宽度不超过 $s_i + 1$（最多选 $s_i$ 件），下标过期即出队；
- 队首对应最优的 $u$，代入即得 $dp[j]$。

**复杂度**：时间 $O(NV)$，空间 $O(V)$。

**样例验证**：与多重背包基础题同构，结果为 $10$（物品 1 取 3 件 + 物品 2 取 1 件）。

#### 代码实现

```cpp
#include <cstring>
#include <iostream>
#include <algorithm>

using namespace std;

const int N = 20010;

int n, m;
int f[N], g[N], q[N];   // g: 上一轮的 f 快照；q: 单调队列（存容量下标）

int main()
{
    cin >> n >> m;
    for (int i = 0; i < n; i++)
    {
        int v, w, s;
        cin >> v >> w >> s;
        memcpy(g, f, sizeof f);              // 快照本轮开始前的 f
        for (int j = 0; j < v; j++)          // 按余数 r = j 分组
        {
            int hh = 0, tt = -1;
            for (int k = j; k <= m; k += v)  // 同一余数类内的容量
            {
                if (hh <= tt && q[hh] < k - s * v)   // 超出 s 件的旧下标出队
                    hh++;
                while (hh <= tt && g[q[tt]] - (q[tt] - j) / v * w <= g[k] - (k - j) / v * w)
                    tt--;                    // 维护单调递减队列
                q[++tt] = k;
                f[k] = g[q[hh]] + (k - q[hh]) / v * w;  // 队首最优
            }
        }
    }

    cout << f[m] << endl;

    return 0;
}
```

### 混合背包问题

- **来源**：AcWing 7. 混合背包问题（XMUOJ JDII128 改编）
- **难度**：Mid

#### 题目描述

有 $N$ 件物品和一个容量为 $V$ 的背包。第 $i$ 件物品有体积 $v_i$、价值 $w_i$ 和数量标记 $s_i$：

- $s_i = -1$：01 背包物品，只能用一次；
- $s_i = 0$：完全背包物品，可用无限次；
- $s_i > 0$：多重背包物品，最多用 $s_i$ 次。

求能装入背包的最大总价值。

**输入**：第一行两个整数 $N, V$；接下来 $N$ 行，每行三个整数 $v_i, w_i, s_i$。

**样例**

```text
4 5
1 2 -1
2 4 1
3 4 0
4 5 2
```

```text
8
```

#### 思路

三种背包一锅烩——**分类处理，读入一件处理一件**：

- $s_i = 0$（完全）：内层**正序**遍历容量；
- $s_i = -1$（01）：按 $s = 1$ 处理，内层**倒序**；
- $s_i > 0$（多重）：**二进制拆分**成若干件 01 物品，再内层**倒序**。

因为完全背包的循环方向与 01/多重相反，最稳妥的做法是**每种物品单独处理、互不干扰**。代码在循环内联完成二进制拆分，无需另开数组存拆分结果，空间仍是 $O(V)$。

**复杂度**：时间 $O\Big(\sum_i \log s_i \times V\Big)$，空间 $O(V)$。

**样例验证**：物品 2（$2,4,1$）+ 物品 3（$3,4$，无限）= 容量 5、价值 $8$；结果正确。

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>

using namespace std;

const int N = 1007;
int n, m;
int f[N];

int main()
{
    cin >> n >> m;

    for (int i = 0; i < n; i++)
    {
        int v, w, s;
        cin >> v >> w >> s;

        if (!s)                       // 完全背包：正序
        {
            for (int j = v; j <= m; j++)
                f[j] = max(f[j], f[j - v] + w);
        }
        else                          // 01 / 多重：二进制拆分 + 倒序
        {
            if (s == -1)
                s = 1;

            for (int k = 1; k <= s; k *= 2)
            {
                for (int j = m; j >= k * v; j--)
                    f[j] = max(f[j], f[j - k * v] + k * w);
                s -= k;
            }
            if (s)
            {
                for (int j = m; j >= s * v; j--)
                    f[j] = max(f[j], f[j - s * v] + s * w);
            }
        }
    }

    cout << f[m] << endl;
    return 0;
}
```

### 二维费用背包问题

- **来源**：AcWing 8. 二维费用的背包问题（XMUOJ JDII210 改编）
- **难度**：Low

#### 题目描述

有 $N$ 件物品和一个背包，背包有两个约束：**体积上限 $V$** 和**重量上限 $M$**：

- 第 $i$ 件物品体积 $v_i$、重量 $m_i$、价值 $w_i$；
- 每件物品至多取一次（01 背包）。

求在体积和重量都不超限的前提下，能获得的最大总价值。

**输入**：第一行三个整数 $N, V, M$；接下来 $N$ 行，每行三个整数 $v_i, m_i, w_i$。

**样例**

```text
4 5 6
1 2 3
2 4 4
3 4 5
4 5 6
```

```text
8
```

#### 思路

二维费用 = 标准 01 背包再多加一维约束。

**状态定义**

$$
dp[j][k] = \text{使用 } j \text{ 体积、} k \text{ 重量时能获得的最大总价值}
$$

**状态转移**（对每件物品双重倒序）：

$$
dp[j][k] = \max\Big(dp[j][k],\ dp[j - v_i][k - m_i] + w_i\Big)
$$

两维容量都必须**倒序**遍历（原因与一维 01 背包相同：防止同一物品被重复取用）。

**复杂度**：时间 $O(N \times V \times M)$，空间 $O(V \times M)$。

**样例验证**：物品 1（$1,2,3$）+ 物品 3（$3,4,5$）= 体积 4、重量 6、价值 $8$，恰好在双重限制内取到最大。

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>

using namespace std;

const int MAX_V = 505;
const int MAX_M = 505;

int dp[MAX_V][MAX_M];

int main()
{
    int N, V, M;
    cin >> N >> V >> M;

    for (int i = 0; i <= V; i++)
        for (int j = 0; j <= M; j++)
            dp[i][j] = 0;

    for (int i = 0; i < N; i++)
    {
        int vi, mi, wi;
        cin >> vi >> mi >> wi;

        for (int j = V; j >= vi; j--)          // 体积倒序
            for (int k = M; k >= mi; k--)      // 重量倒序
                dp[j][k] = max(dp[j][k], dp[j - vi][k - mi] + wi);
    }

    cout << dp[V][M] << endl;

    return 0;
}
```

### 分组背包问题

- **来源**：AcWing 9. 分组背包问题（XMUOJ JDII127 改编）
- **难度**：High

#### 题目描述

有 $N$ 组物品和一个容量为 $V$ 的背包，**同一组内最多选一件**（也可一件不选）：

- 第 $i$ 组有 $S_i$ 件物品，第 $j$ 件重量 $w_{ij}$、价值 $v_{ij}$。

求能装入背包的最大总价值。

**输入**：第一行两个整数 $N, V$；接下来 $N$ 组数据：每组第一行为 $S_i$，之后 $S_i$ 行每行两个整数 $w, v$。

**样例**

```text
3 5
2
1 2
2 4
1
3 4
1
4 5
```

```text
8
```

#### 思路

分组背包 = 01 背包的变体：**每组至多取一件**，把"选或不选一件"升级为"选组内的哪一件或一件不选"。

**状态定义**：$dp[j] = $ 容量为 $j$ 时能获得的最大总价值。

**状态转移**：三层循环——外层组、中层容量（倒序）、内层组内物品：

$$
dp[j] = \max\Big(dp[j],\ dp[j - w_{ik}] + v_{ik}\Big)
$$

- 内层遍历同组所有物品取最优，等价于决定"这一组选哪一件"；
- 容量**倒序**（同 01 背包）：保证每组至多选一件——若正序，同一组内的物品会相互叠加。

**复杂度**：时间 $O\Big(\sum_i S_i \times V\Big)$，空间 $O(V)$。

**样例验证**：组 1 选第 2 件（$2,4$）+ 组 2 选（$3,4$）= 容量 5、价值 $8$；组 3 的（$4,5$）已无容量，结果为 $8$。

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>

using namespace std;

int n, m;
int v[110][110], w[110][110], f[110], s[110];

int main()
{
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++)
    {
        scanf("%d", &s[i]);
        for (int j = 1; j <= s[i]; j++)
            scanf("%d%d", &v[i][j], &w[i][j]);
    }

    for (int i = 1; i <= n; i++)            // 外层：组
        for (int j = m; j >= 1; j--)        // 中层：容量倒序
            for (int k = 1; k <= s[i]; k++) // 内层：组内物品
                if (v[i][k] <= j)
                    f[j] = max(f[j], f[j - v[i][k]] + w[i][k]);

    printf("%d", f[m]);

    return 0;
}
```

### 有依赖的背包问题（树形）

- **来源**：AcWing 10. 有依赖的背包问题（XMUOJ JDII212 改编）
- **难度**：Low

#### 题目描述

有 $N$ 件物品和一个容量为 $V$ 的背包，物品之间存在**依赖关系**，构成一棵树：

- 选择某件物品前，必须先选它的父节点（根节点除外）；
- 第 $i$ 件物品体积 $v_i$、价值 $w_i$，每件至多取一次。

求在依赖约束下能装入的最大总价值。

**输入**：第一行两个整数 $N, V$；接下来 $N$ 行，每行三个整数 $v_i, w_i, p_i$（$p_i = -1$ 表示根节点）。

**数据范围**：$1 \le N, V \le 100$。

**样例**

```text
5 7
2 3 -1
2 2 1
3 5 1
4 7 2
3 6 2
```

```text
11
```

#### 思路

树形 DP + 分组背包思想的结合。**从叶子向根递归**，每个节点返回一维 DP 数组，表示"以该子树为范围、各容量下的最大价值"。

**状态定义**

$$
f[u][j] = \text{以 } u \text{ 为根的子树中、容量 } j \text{ 时的最大价值（节点 } u \text{ 必选）}
$$

**递归过程**（后序：先处理所有儿子，再合并自己）：

1. 对每个儿子 `son`，先递归求出 `f[son]`；
2. 把 `son` 的子树看作"一组"做**分组背包**合并：枚举分给儿子的容量 $k$，

$$
f[u][j] = \max\big(f[u][j],\ f[u][j - k] + f[son][k]\big)
$$

（合并时先给 $u$ 预留体积 $v_u$，否则放不下 $u$ 的组合无效）

3. 合并完所有儿子后把 $u$ 装入：容量 $\ge v_u$ 的 $f[u][j] = f[u][j - v_u] + w_u$，容量 $< v_u$ 的置 $0$。

**复杂度**：时间 $O(N \times V^2)$（每组背包合并 $O(V^2)$），空间 $O(N \times V)$。

**样例验证**：选节点 1（$2,3$）+ 节点 2（$2,2$）+ 节点 5（$3,6$）= 体积 $2+2+3=7$、价值 $3+2+6=11$。

#### 代码实现

```cpp
#include <cstring>
#include <iostream>
#include <algorithm>

using namespace std;

const int N = 110;

int n, m;
int v[N], w[N];
int h[N], e[N], ne[N], idx;
int f[N][N];

void add(int a, int b) { e[idx] = b, ne[idx] = h[a], h[a] = idx++; }

void dfs(int u)
{
    for (int i = h[u]; ~i; i = ne[i])   // 先递归处理所有儿子
    {
        int son = e[i];
        dfs(son);

        for (int j = m - v[u]; j >= 0; j--)       // 预留 u 的体积，容量倒序
            for (int k = 0; k <= j; k++)          // 枚举分给儿子子树的空间
                f[u][j] = max(f[u][j], f[u][j - k] + f[son][k]);
    }

    for (int i = m; i >= v[u]; i--)     // 把 u 自己装入
        f[u][i] = f[u][i - v[u]] + w[u];
    for (int i = 0; i < v[u]; i++)      // 容量放不下 u → 整棵子树作废
        f[u][i] = 0;
}

int main()
{
    cin >> n >> m;

    memset(h, -1, sizeof h);
    int root;
    for (int i = 1; i <= n; i++)
    {
        int p;
        cin >> v[i] >> w[i] >> p;
        if (p == -1)
            root = i;
        else
            add(p, i);
    }

    dfs(root);

    cout << f[root][m] << endl;

    return 0;
}
```

### 背包问题求方案数

- **来源**：AcWing 11. 背包问题求方案数（XMUOJ JDII213 改编）
- **难度**：Low

#### 题目描述

有 $N$ 件物品和一个容量为 $V$ 的背包。第 $i$ 件物品体积 $v_i$、价值 $w_i$，每件至多取一次（01 背包）。

求：**达到最大总价值的选取方案有多少种**？答案对 $10^9+7$ 取模。

**输入**：第一行两个整数 $N, V$；接下来 $N$ 行，每行两个整数 $v_i, w_i$。

**样例**

```text
4 5
1 2
2 4
3 4
4 6
```

```text
2
```

#### 思路

在求最大价值的同时维护方案数。

**状态定义**

$$
f[j] = \text{容量 } j \text{ 时的最大价值}, \qquad g[j] = \text{达到该价值的方案数}
$$

**初始化**：$f$ 全部置 $-\infty$，$f[0] = 0$（恰好用 0 容量、价值 0 是合法起点），$g[0] = 1$。

**转移**（01 背包倒序）：

$$
\text{maxv} = \max\big(f[j],\ f[j - v_i] + w_i\big)
$$

- 若 $f[j] = \text{maxv}$，累加"不选第 $i$ 件"的方案数 $g[j]$；
- 若 $f[j - v_i] + w_i = \text{maxv}$，累加"选第 $i$ 件"的方案数 $g[j - v_i]$；
- 最后 $f[j] = \text{maxv}$，$g[j]$ 为上述累加（取模）。

**关键点**：最优解**不要求恰好装满**。DP 结束后需遍历所有容量 $j$ 找出最大价值 $f_{\max}$，再累加所有 $f[j] = f_{\max}$ 对应的 $g[j]$。

**复杂度**：时间 $O(NV)$，空间 $O(V)$。

**样例验证**：容量 5 的最大价值 $8$：方案 ① 选物品 1 + 4（$2+6$），方案 ② 选物品 2 + 3（$4+4$），共 $2$ 种。

#### 代码实现

```cpp
#include <cstring>
#include <iostream>

using namespace std;

const int N = 1010, mod = 1e9 + 7;

int n, m;
int f[N], g[N];

int main()
{
    cin >> n >> m;

    memset(f, -0x3f, sizeof f);
    f[0] = 0;
    g[0] = 1;

    for (int i = 0; i < n; i++)
    {
        int v, w;
        cin >> v >> w;
        for (int j = m; j >= v; j--)
        {
            int maxv = max(f[j], f[j - v] + w);
            int s = 0;
            if (f[j] == maxv)                // 不选第 i 件
                s = g[j];
            if (f[j - v] + w == maxv)        // 选第 i 件
                s = (s + g[j - v]) % mod;
            f[j] = maxv, g[j] = s;
        }
    }

    int res = 0;
    for (int i = 1; i <= m; i++)
        if (f[i] > f[res])
            res = i;

    int sum = 0;
    for (int i = 0; i <= m; i++)
        if (f[i] == f[res])
            sum = (sum + g[i]) % mod;

    cout << sum << endl;

    return 0;
}
```

### 背包问题求具体方案

- **来源**：AcWing 12. 背包问题求具体方案（XMUOJ JDII214 改编）
- **难度**：Low

#### 题目描述

有 $N$ 件物品和一个容量为 $V$ 的背包。第 $i$ 件物品体积 $v_i$、价值 $w_i$，每件至多取一次（01 背包）。

求：输出达到最大总价值的具体方案——**所选物品的编号序列**。若有多组最优解，输出**字典序最小**的。

**输入**：第一行两个整数 $N, V$；接下来 $N$ 行，每行两个整数 $v_i, w_i$。

**样例**

```text
4 5
1 2
2 4
3 4
4 6
```

```text
1 4
```

#### 思路

DP 完成后反向推导选哪些物品，并利用遍历顺序保证字典序最小。

**状态定义**（**从后往前**递推，便于回溯）：

$$
f[i][j] = \text{考虑第 } i \text{ 到第 } N \text{ 件物品、容量 } j \text{ 时的最大价值}
$$

$$
f[i][j] = \max\Big(f[i+1][j],\ f[i+1][j - v_i] + w_i\Big)
$$

**回溯输出**（从第 1 件开始贪心）：对每个 $i$，若 $j \ge v_i$ 且 $f[i][j] = f[i+1][j - v_i] + w_i$（选第 $i$ 件不劣于不选），则**选**它并输出 $i$，令 $j -= v_i$。

- 从编号 1 开始、能选就选 → 得到的编号序列**字典序最小**；
- 必须用二维数组保留全部状态，否则无法回溯。

**复杂度**：时间 $O(NV)$，空间 $O(NV)$。

**样例验证**：容量 5 的最大价值 $8$ 有两种方案 $\{1,4\}$、$\{2,3\}$，按字典序取 $\{1,4\}$。

#### 代码实现

```cpp
#include <iostream>

using namespace std;

const int N = 1010;

int n, m;
int v[N], w[N];
int f[N][N];

int main()
{
    cin >> n >> m;
    for (int i = 1; i <= n; i++)
        cin >> v[i] >> w[i];

    // 从后往前递推
    for (int i = n; i >= 1; i--)
        for (int j = 0; j <= m; j++)
        {
            f[i][j] = f[i + 1][j];
            if (j >= v[i])
                f[i][j] = max(f[i][j], f[i + 1][j - v[i]] + w[i]);
        }

    // 从前往后贪心回溯，保证字典序最小
    int j = m;
    for (int i = 1; i <= n; i++)
        if (j >= v[i] && f[i][j] == f[i + 1][j - v[i]] + w[i])
        {
            cout << i << ' ';
            j -= v[i];
        }

    return 0;
}
```

### 能量石（贪心 + 01 背包）

- **来源**：AcWing 734. 能量石（XMUOJ JDII215 改编）
- **难度**：Low

#### 题目描述

有 $N$ 块能量石，每块石头有三个属性：

- $S_i$：吃掉它需要的时间；
- $E_i$：它初始蕴含的能量；
- $L_i$：每等待一息流失的能量（流失到 $0$ 为止，不会为负）。

可以按任意顺序吃掉若干块石头（一旦开始不能中断）。求能获得的最大总能量。

**输入**：第一行整数 $T$（测试组数）；每组第一行整数 $N$；接下来 $N$ 行每行三个整数 $S_i, E_i, L_i$。

**数据范围**：$1 \le T \le 10$，$1 \le N \le 100$，$1 \le S_i \le 100$，$1 \le E_i \le 10^5$，$0 \le L_i \le 10^5$。

**样例**

```text
3
4
20 10 1
5 30 5
100 30 1
5 80 60
3
10 4 1000
10 3 1000
10 8 1000
2
12 300 50
5 200 0
```

```text
Case #1: 105
Case #2: 8
Case #3: 500
```

#### 思路

**第一步：贪心定顺序。** 石头的能量在等待中不断流失，所以"怎么吃"和"吃哪些"都要决定。

用**交换论证**：对任意相邻两块 $a, b$，先吃 $a$ 再吃 $b$ 的总收益 $\ge$ 先吃 $b$ 再吃 $a$ 的收益，当且仅当

$$
S_a \cdot L_b \le S_b \cdot L_a
$$

（直观理解：耗时短、流失快的石头先吃，避免能量白白流走）。按此规则对所有石头排序。

**第二步：01 背包选石头。** 排序后，问题变成"选哪些吃、总耗时不超过 $T$ 的最大能量"：

$$
f[i][j] = \max\Big(f[i-1][j],\ f[i-1][j - S_i] + \max\big(0,\ E_i - L_i \cdot (j - S_i)\big)\Big)
$$

其中 $j - S_i$ 是开始吃第 $i$ 块之前已经过的时间，能量 $E_i$ 在等待中损失了 $L_i \times (j - S_i)$（下限 $0$）。

**注意**：最优解**不要求恰好用满总时间**，最后枚举所有 $j$ 取 $f[N][j]$ 的最大值。总时间上限 $= \sum S_i$。

**复杂度**：时间 $O(N \times \sum S_i)$，空间 $O(\sum S_i)$（可优化为一维）。

**样例验证**：Case #1 排序后按最优顺序取，最大能量 $105$；Case #2 三块石头流失率都极高，等待期间其余全部流尽，只能取一块，最大 $8$；Case #3 先吃第一块（$300$）再吃第二块（$200$，$L=0$ 不流失）= $500$。

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>

using namespace std;

const int N = 110, M = 10010;

int n;
struct Stone
{
    int s, e, l;
} stones[N];

bool cmp(Stone a, Stone b)
{
    return a.s * b.l < b.s * a.l;
}

int f[N][M];

int main()
{
    int T;
    cin >> T;
    for (int C = 1; C <= T; C++)
    {
        cin >> n;
        int m = 0;
        for (int i = 1; i <= n; i++)
        {
            int s, e, l;
            cin >> s >> e >> l;
            stones[i] = {s, e, l};
            m += s;                       // 总时间上限
        }

        sort(stones + 1, stones + 1 + n, cmp);

        for (int i = 1; i <= n; i++)
            for (int j = 0; j <= m; j++)
            {
                f[i][j] = f[i - 1][j];
                if (j >= stones[i].s)
                {
                    int s = stones[i].s, e = stones[i].e, l = stones[i].l;
                    f[i][j] = max(f[i][j], f[i - 1][j - s] + max(0, e - l * (j - s)));
                }
            }

        int res = 0;
        for (int i = 0; i <= m; i++)
            res = max(res, f[n][i]);

        printf("Case #%d: %d\n", C, res);
    }

    return 0;
}
```

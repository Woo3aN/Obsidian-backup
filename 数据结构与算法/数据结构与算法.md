# 动态规划

## 背包 DP 概述

**背包问题（Knapsack Problem）** 是经典的组合优化问题：在容量有限的背包中装入若干物品（各有体积 / 重量与价值），在不超过容量上限的前提下求最大总价值。

按物品的可选次数分为三类，核心都是一维滚动数组：

| 类型    | 物品限制          | 核心处理             | 时间复杂度                      |
| :---- | :------------ | :--------------- | :------------------------- |
| 01 背包 | 每件最多取 1 次     | 内层**倒序**         | $O(NV)$                    |
| 完全背包  | 每件可取无限次       | 内层**正序**         | $O(NV)$                    |
| 多重背包  | 每件最多取 $s_i$ 次 | **二进制拆分** + 内层倒序 | $O(\sum \log s_i \cdot V)$ |

> 01 背包与完全背包的**唯一区别**是内层循环方向；多重背包则需先**二进制拆分**，再按 01 背包处理。推导详见下方各题笔记。

```cpp
// 01 背包：内层倒序，每件物品只能用一次
for (int i = 1; i <= n; i++)
    for (int j = m; j >= v[i]; j--)
        f[j] = max(f[j], f[j - v[i]] + w[i]);

// 完全背包：内层正序，每件物品可无限使用
for (int i = 1; i <= n; i++)
    for (int j = v[i]; j <= m; j++)
        f[j] = max(f[j], f[j - v[i]] + w[i]);

// 多重背包：先二进制拆分，再按 01 背包（倒序）处理
int cnt = 0;
for (int i = 1; i <= n; i++)
{
    int a, b, s;                    // 体积、价值、数量
    cin >> a >> b >> s;
    int k = 1;
    while (k <= s)                  // 1, 2, 4, ...
    {
        cnt++;
        v[cnt] = a * k;
        w[cnt] = b * k;
        s -= k;
        k *= 2;
    }
    if (s > 0)                      // 余数
    {
        cnt++;
        v[cnt] = a * s;
        w[cnt] = b * s;
    }
}
for (int i = 1; i <= cnt; i++)
    for (int j = m; j >= v[i]; j--)
        f[j] = max(f[j], f[j - v[i]] + w[i]);
```

## 01 背包问题

- **来源**：AcWing 2. 01 背包问题 / AcWing 423. 采药（XMUOJ JDII198 改编）
- **难度**：Low

### 题目描述

有 $M$ 件物品和一个容量为 $T$ 的背包：

- 第 $i$ 件物品体积为 $v_i$，价值为 $w_i$；
- 每件物品**只有一件**，取或不取（对应 01 背包）。

求在总体积不超过 $T$ 的条件下，能获得的最大总价值。

**输入**：第一行两个整数 $T, M$（背包容量、物品数），用空格隔开；接下来 $M$ 行，每行两个整数 $v_i, w_i$（体积、价值）。

**数据范围**：$1 \le T \le 1000$，$1 \le M \le 100$。

**样例**

```text
70 3
71 100
69 1
1 2
```

```text
3
```

### 思路

**朴素二维写法**

$$
dp[i][j] = \text{从前 } i \text{ 件物品中选、容量不超过 } j \text{ 时的最大价值}
$$

对第 $i$ 件物品，分「取」与「不取」两种情况：

$$
dp[i][j] = \max\Big(dp[i-1][j],\ dp[i-1][j - v_i] + w_i\Big)
$$

- 不取：$dp[i-1][j]$；
- 取（需 $j \ge v_i$）：$dp[i-1][j - v_i] + w_i$。

初始化 $dp[0][j] = 0$，答案即 $dp[M][T]$。时间 $O(M \times T)$，空间 $O(M \times T)$。

**一维滚动数组优化**

观察转移方程，第 $i$ 行只依赖第 $i-1$ 行，可压成一维：

$$
dp[j] = \max\Big(dp[j],\ dp[j - v_i] + w_i\Big)
$$

内层 $j$ 必须**从大到小（倒序）** 遍历：

```cpp
for (int j = m; j >= v[i]; j--)
    f[j] = max(f[j], f[j - v[i]] + w[i]);
```

**为什么倒序？** 转移用到的 $dp[j - v_i]$ 必须是「前 $i-1$ 件」的旧值。若正序遍历，$dp[j - v_i]$ 已在当前轮被更新（可能已包含第 $i$ 件），会导致第 $i$ 件被重复选取，退化成完全背包。倒序保证当前轮更新的 $dp[j]$ 不会影响本轮更大的 $j$，每种物品至多取一次。

**复杂度**

- 时间：$O(M \times T)$
- 空间：$O(T)$（一维）

**样例验证**：容量 $T = 70$，第 1 件（$71, 100$）体积 $71 > 70$ 放不下；第 2 件（$69, 1$）+ 第 3 件（$1, 2$）共耗时 $69 + 1 = 70$，价值 $1 + 2 = 3$，为最大。

### 代码实现

```cpp
#include <cstring>
#include <iostream>
#include <algorithm>

using namespace std;

const int N = 1010;

int m, n;
int f[N];

int main()
{
    cin >> m >> n;

    // 读入即处理，无需存储全部物品
    for (int i = 0; i < n; i++)
    {
        int v, w;
        cin >> v >> w;
        // 01 背包：内层倒序遍历
        for (int j = m; j >= v; j--)
            f[j] = max(f[j], f[j - v] + w);
    }

    cout << f[m] << endl;

    return 0;
}
```

## 完全背包问题

- **来源**：AcWing 3. 完全背包问题（XMUOJ JDII122 改编）
- **难度**：High

### 题目描述

有 $N$ 种物品和一个容量为 $V$ 的背包：

- 第 $i$ 种物品体积为 $v_i$，价值为 $w_i$；
- 每种物品**数量无限**，可取任意件。

求能装入背包的最大总价值。

**输入**：第一行两个整数 $N, V$，用空格隔开；接下来 $N$ 行，每行两个整数 $v_i, w_i$。

**样例**

```text
7 884
6148 6786
8500 8620
6136 6930
8700 6732
409 3388
9925 642
4324 5208
```

```text
6776
```

### 思路

**状态定义**

$$
dp[j] = \text{容量为 } j \text{ 时能获得的最大总价值}
$$

初始化全部为 $0$（什么都不装的价值为 $0$）。

**状态转移**

对每种物品 $i$，**正序**遍历容量 $j$（从 $v_i$ 到 $V$）：

$$
dp[j] = \max\Big(dp[j],\ dp[j - v_i] + w_i\Big)
$$

**为什么正序？** 这是完全背包与 01 背包唯一的不同点：

- **倒序**更新时，更新 $dp[j]$ 用到的 $dp[j - v_i]$ 是上一轮（不含第 $i$ 种物品）的结果，保证每种物品至多取一次；
- **正序**更新时，$dp[j - v_i]$ 可能已经放入了第 $i$ 种物品，于是该物品可以被**反复取用**，恰好实现「无限次」的限制。

**复杂度**

- 时间：$O(N \times V)$
- 空间：$O(V)$

**样例验证**：容量为 $884$，只有第 5 件物品体积 $409 \le 884$ 可装入，最多取 $\lfloor 884 / 409 \rfloor = 2$ 件，最大价值 $= 2 \times 3388 = 6776$。

### 代码实现

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int N = 1010;
int n, m;
int v[N], w[N];
int f[N];

int main()
{
    cin >> n >> m;
    for (int i = 1; i <= n; i++)
        cin >> v[i] >> w[i];

    // 完全背包：内层正序遍历容量
    for (int i = 1; i <= n; i++)
        for (int j = v[i]; j <= m; j++)
        {
            f[j] = max(f[j], f[j - v[i]] + w[i]);
        }

    cout << f[m] << endl;

    return 0;
}
```

## 多重背包问题

- **来源**：AcWing 4. 多重背包问题 I（XMUOJ JDII126 改编）
- **难度**：High

### 题目描述

有 $N$ 种物品和一个容量为 $V$ 的背包：

- 第 $i$ 种物品重量为 $w_i$、价值为 $v_i$、**数量最多 $s_i$ 件**；
- 每种物品最多取 $s_i$ 件。

求能装入背包的最大总价值。

**输入**：第一行两个整数 $N, V$，用空格隔开；接下来 $N$ 行，每行三个整数 $w_i, v_i, s_i$。

**样例**

```text
4 5
1 2 3
2 4 1
3 4 3
4 5 2
```

```text
10
```

### 思路

多重背包 = 01 背包 + 数量限制。

**朴素做法**：把第 $i$ 种物品的 $s_i$ 件逐件拆开，视为 $s_i$ 件独立的 01 背包物品。但 $s_i$ 可能很大，复杂度 $O(\sum s_i \times V)$ 不可行。

**二进制拆分优化**

将 $s_i$ 分解为若干份：

$$
1,\ 2,\ 4,\ \dots,\ 2^k,\ \text{余数 } r
$$

其中 $1 + 2 + \dots + 2^k \le s_i$，余数 $r = s_i - (1 + 2 + \dots + 2^k)$。这些份的子集之和能覆盖 $0$ 到 $s_i$ 的**任意整数**，因此拆分后物品的选择范围与原题完全等价。

把每一份打包成一件新的 01 背包物品：

$$
\text{重量} = \text{份数} \times w_i, \qquad \text{价值} = \text{份数} \times v_i
$$

拆分后物品总数降为 $\sum \log s_i$，再跑标准 01 背包（内层**倒序**）：

$$
dp[j] = \max\Big(dp[j],\ dp[j - w] + v\Big)
$$

**为什么份数按 $1,2,4,\dots$ 取？** 二进制表示的任意整数都可由此拼出——例如 $s = 13 \Rightarrow 1,2,4,6$，子集和可覆盖 $0 \sim 13$。这样把「取 $k$ 件」这一维选择压缩成了 $\log s_i$ 个 01 决策。

**复杂度**

- 时间：$O\Big(\sum_i \log s_i \times V\Big)$
- 空间：$O(V)$

**进一步优化**：单调队列优化可将复杂度降至 $O(N \times V)$（对每种物品按模 $w_i$ 的剩余类分别维护滑动窗口最大值）。本题用二进制拆分即可满足要求。

**样例验证**：取 3 件物品 1（重 $3$、价 $6$）+ 1 件物品 2（重 $2$、价 $4$）= 总重量 $5$、总价值 $10$，恰好装满。

### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>

using namespace std;

const int N = 12010, M = 2010;   // N: 拆分后的物品上限（Σlog s_i），M: 背包容积

int n, m;
int v[N], w[N];
int f[M];

int main()
{
    cin >> n >> m;
    int cnt = 0;                // 拆分后新物品的个数
    for (int i = 1; i <= n; i++)
    {
        int a, b, s;            // 重量、价值、数量
        cin >> a >> b >> s;
        int k = 1;
        while (k <= s)          // 按 1, 2, 4, ... 拆分
        {
            cnt++;
            v[cnt] = a * k;
            w[cnt] = b * k;
            s -= k;
            k *= 2;
        }

        if (s > 0)              // 剩余部分作为最后一件
        {
            cnt++;
            v[cnt] = a * s;
            w[cnt] = b * s;
        }
    }
    n = cnt;

    // 拆分完毕后跑标准 01 背包：内层倒序遍历
    for (int i = 1; i <= n; i++)
        for (int j = m; j >= v[i]; j--)
            f[j] = max(f[j], f[j - v[i]] + w[i]);

    cout << f[m] << endl;
    return 0;
}
```

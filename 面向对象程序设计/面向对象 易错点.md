# 左值、右值和引用
## 一、先抓核心区别：左值和右值的本质

一个最简单的判断标准：

- **左值 (lvalue)**：**有名字、有内存地址、能被取地址 & 的值**。可以出现在赋值号 `=` 的左边。
- **右值 (rvalue)**：**没有名字、临时的、用完就消失、不能被取地址 & 的值**。只能出现在赋值号 `=` 的右边。

举个最直白的例子：

cpp

运行

```cpp
int a = 10; // a 是左值，10 是右值
int b = a;  // a 是左值，可以被复制；这里 b 也是左值
```

---

## 二、深入拆解：左值、右值的常见场景

### 1. 典型的左值

只要你能对它取地址 `&`，它就是左值：

cpp

运行

```cpp

int x = 5;
int *p = &x; // ✅ 可以取地址，x 是左值

int arr[3] = {1,2,3};
int *q = &arr[0]; // ✅ 数组元素是左值

int& func() { static int s = 10; return s; }
int *r = &func(); // ✅ 函数返回的引用是左值
```

特点总结：有名字、有稳定内存地址，程序运行期间它一直存在。

### 2. 典型的右值

你**不能**对它取地址，它是临时的：

cpp

运行

```cpp
int a = 10;
int b = a + 5;
// 10 是字面量右值，a+5 是计算产生的临时值，也是右值

int func() { return 20; }
int c = func(); // func() 返回的是临时值，右值
```

特点总结：用完就扔，编译器会在合适的地方把它销毁。

### 一、先明确两个核心概念

1. **引用的本质**：引用就是**给已有的变量起了一个别名**，和原变量共享同一块内存。
2. **绑定**：就是 “引用指向哪个对象 / 值” 的过程。

---

### 二、逐行拆解表格里的三种引用类型

#### 1. 普通左值引用 `T&`

表格

| 可以绑定左值？ | 可以绑定右值？ |
| :------ | :------ |
| ✅ 是     | ❌ 否     |

**含义**：只能绑定到**有名字、有地址、能取 `&`** 的左值，不能绑定到临时的右值。

**例子**：

cpp

运行

```cpp
int a = 10; // a 是左值
int& r1 = a;  // ✅ 合法：r1 是 a 的别名，绑定左值 a
r1 = 20;      // 合法：修改 r1 就是修改 a

int& r2 = 10; // ❌ 报错：10 是右值，普通左值引用不能绑定右值
int& r3 = a + 5; // ❌ 报错：a+5 是临时计算结果，属于右值
```

**为什么不能绑定右值？**

因为普通左值引用允许修改绑定的对象，但右值是临时的、用完就销毁的，修改它没有意义，还容易引发未定义行为，所以 C++ 直接禁止了这种绑定。

---

#### 2. const 左值引用 `const T&`

表格

|可以绑定左值？|可以绑定右值？|
|:--|:--|
|✅ 是|✅ 是|

**含义**：既可以绑定左值，也可以绑定右值，而且绑定右值时，会**延长临时右值的生命周期**，直到这个引用离开作用域。

**例子**：

cpp

运行

```cpp
int a = 10;
const int& r1 = a;  // ✅ 合法：绑定左值，r1 是 a 的只读别名
// r1 = 20; // 报错：const 引用不能修改值

const int& r2 = 10; // ✅ 合法：绑定右值，临时值的生命周期被延长
const int& r3 = a + 5; // ✅ 合法：绑定右值
```

**为什么可以绑定右值？**

因为 `const` 引用不允许修改绑定的对象，绑定临时右值不会出现 “修改临时值” 的问题，所以 C++ 允许这种绑定，还顺便延长了临时值的生命周期。

---

#### 3. 右值引用 `T&&`

表格

|可以绑定左值？|可以绑定右值？|
|:--|:--|
|❌ 否（除非用 `std::move` 转换）|✅ 是|

**含义**：专门用来绑定临时的右值，支持移动语义；如果想绑定左值，需要用 `std::move` 把左值 “强制转换” 成右值。

**例子**：

cpp

运行

```cpp
int a = 10;
int&& r1 = 10;      // ✅ 合法：绑定右值
int&& r2 = a + 5;   // ✅ 合法：绑定右值
int&& r3 = a;       // ❌ 报错：a 是左值，不能直接绑定到右值引用

// 用 std::move 把左值 a 转换成右值，就可以绑定了
int&& r4 = std::move(a); // ✅ 合法
```

**关键注意点**：

右值引用本身是**左值**！比如上面的 `r1`，它是右值引用类型，但它有名字、有地址，所以它本身是左值。这也是你之前题目里 `int&& x` 函数形参里 `int& y = x;` 能通过编译的原因。

---

### 三、一张表总结核心区别

表格

| 引用类型       | 允许修改绑定对象？ | 绑定左值             | 绑定右值 | 核心用途           |
| :--------- | :-------- | :--------------- | :--- | :------------- |
| `T&`       | ✅ 可以      | ✅                | ❌    | 读写访问左值对象       |
| `const T&` | ❌ 不可以     | ✅                | ✅    | 只读访问，延长临时值生命周期 |
| `T&&`      | ✅ 可以      | ❌（需 `std::move`） | ✅    | 移动语义，接管临时对象资源  |
